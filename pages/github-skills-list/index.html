GitHub 可用 Skills 一览

截至 2026 年 5 月，GitHub 上已有数百个 Agent Skills 仓库。本文按官方、社区、垂直领域、安全等维度分类整理目前可用的 Skills 资源。

# 一、官方 Skills（大厂维护）

# Anthropic 官方 — anthropics/skills (opens new window) ⭐ 136k

Claude Code 的官方 Skills，约 18 个，是事实上的标准规范：

Skill 用途
algorithmic-art 算法生成艺术（p5.js）
brand-guidelines 品牌设计规范应用
canvas-design Canvas 设计（海报、UI 等）
frontend-design 前端界面设计与实现
mcp-builder MCP 服务器构建指南
webapp-testing Web 应用 Playwright 测试
slack-gif-creator Slack GIF 动图制作
skill-creator 创建新 Skill 的模板和指南
docx / pptx / xlsx / pdf 办公文档生成与处理
internal-comms 内部沟通文档撰写
theme-factory 主题/样式工厂

安装：Claude Code 中 /plugin marketplace add anthropics/skills

# OpenAI/Codex 官方 — openai/skills (opens new window) ⭐ 10.5k

Codex 官方 Skills，采用三层结构（.system/ 自动安装、.curated/ 精选、.experimental/ 实验）：

层级 代表 Skills
System gh-address-comments、gh-fix-ci、security-best-practices
Curated linear（项目管理）、notion-*（文档协作）、playwright（E2E 测试）、jupyter-notebook
Experimental imagegen、sora（视频生成）、render-deploy、netlify-deploy、vercel-deploy、yeet

# Vercel 官方 — vercel-labs/agent-skills (opens new window) ⭐ 21.8k

Skill 用途
vercel-react-best-practices React/Next.js 性能优化
vercel-composition-patterns React 组合模式（含 React 19 API）
vercel-react-view-transitions View Transition API 动画
vercel-react-native-skills React Native / Expo 开发
web-design-guidelines Web 界面设计规范审查
deploy-to-vercel Vercel 部署

安装：npx skills add vercel-labs/agent-skills

# JetBrains 官方精选 — JetBrains/skills (opens new window) ⭐ 126 Skills

从 14 个上游仓库精选验证：

  • Anthropic、OpenAI、Google Gemini、Google Workspace（18 个 Skills）
  • Anthony Fu（Vue/Nuxt/Vite 生态）
  • Supabase 工具链
  • Kotlin/Spring 后端开发
  • TeamCity CLI

# 六、总结

2026 年的 Agent Skills 生态已形成三个清晰层次：

  1. 官方层：Anthropic、OpenAI、Vercel、JetBrains 提供基础规范和核心 Skills
  2. 社区层：Superpowers（194k Stars）、planning-with-files 等成为事实标准
  3. 垂直层：科学、医学、Web3 安全、产品管理等专业领域快速涌现

如果想快速上手，推荐从 anthropics/skills（官方）和 nobra/superpowers（社区核心）开始，再根据自身领域从 awesome 索引和垂直仓库中挑选。
