推荐 Skills 与插件安装记录

本文精选社区最值得安装的 Skills 套装和 Plugins。Skill 教 AI "怎么做"（Markdown 指令文件，注入到对话上下文），Plugin 帮 AI "记得住、管得清"（可执行代码，通过 Hook 深度集成到 Claude Code 生命周期）。

# 一、Skills 清单

名称 作用 官网地址
anthropics/skills Anthropic 官方 17 个 Skill，含 mcp-builder、skill-creator 等 https://github.com/anthropics/skills
vercel-labs/agent-skills Vercel 官方 7 个 Skill，React 性能优化、组合模式、部署 https://github.com/vercel-labs/agent-skills
kepano/obsidian-skills Obsidian CEO 维护，Markdown 语法、Bases 数据库、CLI 操作 https://github.com/kepano/obsidian-skills
mattpocock/skills Matt Pocock 29 个 Skill，TDD、调试、设计、审查、写作全流程 https://github.com/mattpocock/skills

# 二、Skills 简介

# Anthropic 官方 Skills

Anthropic 官方出品，17 个 Skill 覆盖 MCP 服务器构建、Skill 开发、代码审查等场景。其中 mcp-builder 支持 Python（FastMCP）和 Node（MCP SDK）双语言，用四阶段流程确保 MCP Server 实现质量。

# Vercel Agent Skills

Vercel 官方维护的前端开发全家桶，含 vercel-react-best-practices（40+ 条性能规则）、vercel-composition-patterns（组件组合模式）、web-design-guidelines（100+ UI/UX 规则）、deploy-to-vercel（一键部署）等 7 个 Skill。

# Obsidian Skills

Obsidian CEO Kepano 维护，让 Claude 理解 Obsidian 生态全部特性，直接操作 vault 笔记。含 obsidian-markdown（wikilink、callout、frontmatter）、obsidian-bases（数据视图）、obsidian-cli（命令行）、json-canvas（画布）、defuddle（网页提取）。

# Matt Pocock Skills

TypeScript 教育者 Matt Pocock（Total TypeScript 创始人）沉淀的 29 个 Skill，覆盖完整软件工程生命周期：tdd（红-绿-重构）、diagnose（系统化调试）、design-an-interface（接口设计）、review（双维度审查）、grill-me（追问式设计审查）、to-prd/to-issues/triage（项目管理）、writing-beats/writing-shape/edit-article（写作）。

# 三、Plugins 清单

名称 作用 官网地址
claude-mem 跨会话持久记忆，向量语义搜索，Token 节省 94% https://github.com/thedotmack/claude-mem
planning-with-files 三文件任务管理（task_plan / findings / progress），防跑偏 https://github.com/OthmanAdi/planning-with-files

# 四、Plugins 简介

# claude-mem

给 Claude Code 装上"长期记忆"。通过 5 个 Hook（SessionStart → UserPromptSubmit → PostToolUse → Summary → SessionEnd）自动捕获上下文，使用 ChromaDB 向量搜索召回相关历史，告别每次重复喂上下文。

# planning-with-files

用 task_plan.md、findings.md、progress.md 三个文件管理复杂任务。2-Action Rule 强制每两步写入发现，出错立即记录，用户随时查看进度调整方向。
